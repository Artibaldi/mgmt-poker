# Развёртывание у себя на компьютере: пошаговая инструкция

Комната (ретранслятор) запускается на ноутбуке руководителя. Сотрудник открывает свою ссылку в браузере
по корпоративному VPN или в той же сети. Никаких серверов в интернете, данные о человеке остаются на
вашем компьютере.

```
ваш ноутбук ── python -m poker.relay (порт 8765) ──┬── ваш браузер: ссылка руководителя
                                                    └── браузер сотрудника по VPN: его ссылка
ВКС с записью идёт параллельно — в любом сервисе.
```

## 0. Что нужно

| Что | Зачем | Проверить |
|---|---|---|
| Python 3.9+ | всё, кроме выгрузки, — только стандартная библиотека | `python3 --version` |
| `requests` или `uv` | выгрузка из Jira | `uv --version` или `pip install requests` |
| Учётка Jira с правом чтения | выгрузка активности | открыть задачи проекта в браузере |
| Корпоративный VPN у обоих **или** одна сеть | чтобы браузер сотрудника достучался до вашего ноутбука | шаг 6 |
| Claude Code (необязательно) | доказательства из комментариев — [llm.md](llm.md) | `claude --version` |

## 1. Забрать проект

```bash
git clone https://github.com/Artibaldi/mgmt-poker.git
cd mgmt-poker
scripts/test.sh          # должно закончиться строкой OK
```

## 2. Креды Jira

```bash
cp .env.example .env     # JIRA_URL, JIRA_PROJECT_KEY, JIRA_USERNAME, JIRA_PASSWORD
```

Или укажите уже существующий файл: `export POKER_ENV=/путь/к/.env`. Файл `.env` в git не попадает.

## 3. Поля вашей Jira

```bash
cp config/jira.example.json config/jira.json
```

Найдите id кастомных полей (эпик, приёмщик, постановщик, ответственный):

```bash
curl -s -u "$JIRA_USERNAME:$JIRA_PASSWORD" "$JIRA_URL/rest/api/2/field" \
  | python3 -c "import json,sys; [print(f['id'], f['name']) for f in json.load(sys.stdin) if f['id'].startswith('customfield')]"
```

Впишите их в `config/jira.json`. Ненужные роли удалите. Если сертификат Jira самоподписанный, поставьте `"verify_ssl": false`.
Если ScriptRunner есть, поставьте `"scriptrunner_commented": true`.

## 4. Реестр команды

```bash
cp config/team.example.json config/team.json
```

Для каждого сотрудника укажите логин Jira, имя для карточек и роль: `system-analyst`, `business-analyst`, `developer`, `qa`,
`devops`, `architect`, `project-manager`, `team-lead`. В `manager.name` впишите своё имя. Файл в git не попадает.

## 5. Адрес комнаты

```bash
cp config/relay.example.json config/relay.json
```

Узнайте свой адрес в VPN:

| ОС | Команда | Что искать |
|---|---|---|
| macOS | `ifconfig \| grep -A2 utun \| grep "inet "` | адрес на интерфейсе VPN (`utun*`, иногда `ppp0`) |
| Windows | `ipconfig` | адаптер VPN → IPv4-адрес |
| Linux | `ip -4 addr` | интерфейс `tun0` / `wg0` / `ppp0` |

Впишите его в `public_url`, например `"http://10.20.30.40:8765"`. Оставьте `"host": "0.0.0.0"`, чтобы комната
слушала и VPN-интерфейс.

## 6. Проверить, что сотрудник до вас достучится

```bash
python3 -m poker.relay
```

С другого устройства в VPN (или попросите коллегу) откройте `http://<ваш-адрес>:8765/health`. Должно вернуться
`{"ok": true}`.

Если не открывается:
- **Файрвол macOS.** «Системные настройки → Сеть → Файрвол → Параметры»: разрешите входящие подключения для
  `python3`. Или на время встречи выключите файрвол, если это разрешено политикой.
- **Файрвол Windows.** Подтвердите доступ для Python в частных сетях при первом запуске.
- **VPN изолирует клиентов друг от друга.** Так бывает в корпоративных VPN: попросите ИТ разрешить порт 8765
  между клиентами или встречайтесь в офисной сети. Если не получается ни так, ни так, смотрите
  «Если VPN нет» ниже.

## 7. Создать встречу

Вы задаёте только человека и период. Карты собираются и запечатываются автоматически, и вы их не видите.

```bash
uv run --with requests python -m poker.new --login jdoe --from 2026-09-01 --to 2026-09-30
# с доказательствами из комментариев через Claude (см. llm.md):
uv run --with requests python -m poker.new --login jdoe --from 2026-09-01 --to 2026-09-30 --llm claude
```

На экране — отчёт без содержания карт и две ссылки. Обе продублированы в `sessions/jdoe_2026-09/links.txt`.

> Проверка без Jira: `python3 -m poker.new --login demo --from 2026-09-01 --to 2026-09-30 --role team-lead --name Алексей --activity examples/demo-activity.json --relay http://localhost:8765`.
> Откройте обе ссылки в двух разных браузерах, например в обычном окне и в приватном.

## 8. Отправить ссылку сотруднику

Вставьте **ссылку сотрудника целиком, вместе с частью после `#`**, в приглашение на ВКС. В ней лежит
половина ключа колоды. Свою ссылку не пересылайте: по ней вы входите как ведущий.

## 9. Провести встречу

1. Запустите комнату: `python3 -m poker.relay` (если она ещё не запущена) и откройте свою ссылку.
2. Начните ВКС с записью и нажмите «● Отметить начало записи ВКС». Тогда в итогах будут таймкоды каждой карты.
3. Когда сотрудник войдёт, колода откроется у обоих одновременно. Оба читают правила и нажимают «Готов».
4. По каждой карте: «Прочитал» → оценка с одним предложением «почему» → «Положить карту» → автоматическое
   вскрытие → разговор → договорённость, которую подтверждают оба. Темп ведёте вы, сотрудник может попросить
   паузу или вернуться к карте.
5. «К итогам» → оба нажимают «Итоги верны» → вы нажимаете «Закрыть встречу».
6. Оба нажимают «Выгрузить .md» или «PDF». В выгрузке оценки и «почему» обоих, данные и договорённости.

## 10. После встречи

- Итоги лежат в `sessions/<login>_<YYYY-MM>/results.md` и `results.json`. Договорённости автоматически
  попадут первыми картами в следующую колоду этого человека.
- Остановите комнату: `Ctrl+C`. Ссылки перестают работать, когда комната остановлена или истёк срок
  (`room_ttl_days`, по умолчанию 14 дней).
- Удалить всё о встрече: `rm -r sessions/<login>_<YYYY-MM>`.

## Автозапуск комнаты на macOS (необязательно)

Чтобы не держать терминал открытым, создайте `~/Library/LaunchAgents/local.mgmt-poker.relay.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>local.mgmt-poker.relay</string>
  <key>WorkingDirectory</key><string>/ПУТЬ/К/mgmt-poker</string>
  <key>ProgramArguments</key><array><string>/usr/bin/python3</string><string>-m</string><string>poker.relay</string></array>
  <key>RunAtLoad</key><true/><key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/mgmt-poker-relay.log</string>
  <key>StandardErrorPath</key><string>/tmp/mgmt-poker-relay.log</string>
</dict></plist>
```

```bash
launchctl load ~/Library/LaunchAgents/local.mgmt-poker.relay.plist     # включить
launchctl unload ~/Library/LaunchAgents/local.mgmt-poker.relay.plist   # выключить
```

## Диагностика

| Симптом | Причина | Что сделать |
|---|---|---|
| У сотрудника страница не открывается | файрвол или изоляция клиентов VPN | шаг 6 |
| «Ссылка неполная» | ссылка обрезана до `#` (так бывает в почте или мессенджере) | отправить ссылку целиком, например текстом в чат ВКС |
| «Ссылка недействительна» | встреча пересоздана с `--force`: старые ссылки больше не действуют | отправить новую ссылку из `links.txt` |
| «Срок комнаты истёк» | прошло `room_ttl_days` | создать встречу заново |
| Висит «Открываем колоду…» | половина ключа в ссылке повреждена | открыть ссылку из `links.txt` заново |
| `Address already in use` | порт занят, комната уже запущена | `lsof -i :8765`, остановить старую или поменять `port` |
| `встреча уже создана` | для этого человека и месяца встреча есть | использовать её ссылки или `--force` |

## Если VPN нет

- **Одна офисная сеть.** Работает так же, только `public_url` — ваш адрес в локальной сети.
- **Внутренний сервер компании.** Ретранслятор работает на любом сервере с Python 3.9+: скопируйте
  проект, запустите `python3 -m poker.relay --host 0.0.0.0` и укажите адрес сервера в `public_url`.
  Перенесите на сервер `sessions/<…>` с `room.json`, `deck.sealed.json` и пустым `room-log.jsonl`.
  Желательно поставить HTTPS-прокси (nginx или Caddy) перед портом 8765.
- **Не выставляйте комнату напрямую в интернет по http.** Колода зашифрована, но оценки после вскрытия и
  договорённости идут открытым текстом. За пределами VPN нужен HTTPS. Модель доверия описана в
  [spec-online.md](spec-online.md).
