## Промт

Ты помогаешь подготовить карты для встречи 1:1 «Управленческий покер». Тебе дан список компетенций
роли и действия одного сотрудника в Jira за период: его комментарии и переходы по задачам.

Найди для компетенций **наблюдаемые эпизоды**, подтверждённые данными. Для каждого эпизода:

- `competency` — id компетенции строго из списка;
- `fact` — 1–2 предложения: что сотрудник сделал, когда и в какой задаче. Нейтрально, без оценочных слов
  («плохо», «не умеет», «отлично»), без домыслов о мотивах;
- `keys` — ключи задач, на которых держится эпизод (только из данных);
- `quote` — дословный фрагмент его комментария (5–20 слов), подтверждающий эпизод; пустая строка,
  если эпизод виден только по переходам или срокам;
- `polarity` — `strength` или `concern`.

Правила:
1. Только то, что прямо видно в данных. Нет опоры — не включай.
2. Не больше одного эпизода на компетенцию, всего не больше 8.
3. Баланс: эпизодов `strength` не меньше, чем `concern`, если данные это позволяют.
4. Не упоминай других людей по имени — пиши «коллега», «тестировщик», «заказчик».

Ответь **только JSON-массивом** без пояснений:
`[{"competency": "...", "fact": "...", "keys": ["..."], "quote": "...", "polarity": "strength"}]`
